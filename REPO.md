# Dados para o repositório no GitHub (não precisa subir este arquivo)

## Nome do repositório
ghostpad

## Descrição (campo "About", até 350 caracteres)
Use o celular como ponte Bluetooth para jogar no PC com qualquer controle: o celular lê o controle e o Windows enxerga um Xbox 360 virtual. App desktop em Python + Flet com painel de status, QR Code e instalador do driver.

## Descrição curta (alternativa)
🎮 Celular como ponte Bluetooth para o seu controle no PC. Xbox 360 virtual via ViGEm. Python + Flet.

## Tópicos (Topics)
python, flet, gamepad, controller, bluetooth, ps4-controller, vigem, xinput, websocket, windows, desktop-app

## Texto da primeira Release (v1.0.0)
**GhostPad 1.0.0**

Primeira versão. Use o celular como ponte Bluetooth para jogar no PC com o seu controle.

- Painel de status: driver, servidor, celular, controle e controle virtual
- Endereço, porta e QR Code para abrir no celular
- Botão para instalar o driver ViGEmBus
- Tutorial dentro do app

Baixe `GhostPad.exe`, execute e siga a aba TUTORIAL. Requer Windows 10/11 e celular no mesmo Wi-Fi.
